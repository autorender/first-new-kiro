# First.new for Kiro

Build, preview, edit, and publish web apps from a prompt with your First.new account.

[![Add to Kiro](https://kiro.dev/images/add-to-kiro.svg)](https://kiro.dev/launch/mcp/add?name=first-new&config=%7B%22url%22%3A%22https%3A%2F%2Fmcp.first.new%2Fmcp%22%7D)

Open the install link, confirm the server in Kiro, and sign in to First.new when prompted. Ask Kiro to use First.new to list your projects to verify the connection.
